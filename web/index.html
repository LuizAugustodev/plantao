Jornal de tecnologia que se monta sozinho. Projeto pessoal de Luiz Augusto, dev full stack em Cuiabá. Código aberto no GitHub. Também faço sites na Ziul.

Como funciona

  1. O GitHub Actions coleta as fontes: RSS, Hacker News, CISA e GitHub
  2. Classifica por editoria e marca o que é da minha stack
  3. Publica uma página estática no GitHub Pages, sem servidor
